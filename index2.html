🔥 Connect Your Firebase Project

VoxPop uses Firebase so every user shares polls in real time across all devices. Set up your free Firebase project in 4 steps:

1
Visit console.firebase.google.com → Add project → give it a name (Analytics optional)
2
Go to Build → Firestore Database → Create database → pick Start in test mode → choose a region
3
Go to Build → Authentication → Get started → enable the Email/Password sign-in provider
4
Go to Project Settings → Your apps → click </> → Register web app → copy the config values below

Your config is only stored in this browser's localStorage.
